# v1.2.1 Audit — findings and skeptic verdicts

> **Purpose**: the evidence behind the v1.2.1 roadmap. Every cleanup item in `ROADMAP.md` traces back to a finding id here.
> **Stability**: frozen snapshot (audited 2026-09-17/18 against `bcb34bd5`, whose source equals the v1.2.1 branch point). Do not edit findings; record what actually happened in `../V1.2.1_STATUS.md`.
> **How to use**: large file — grep for a finding id (`dead-modules/ZOMBIE-04`), a file name, or the "ALIVE or deliberate" lists before deleting anything. Never read it whole.

## Method

Ten area explorers, read-only, each seeded with measured data (real TypeScript AST complexity, import-graph reachability from `src/extension.ts`, a normalized-window clone detector, Lizard for Python and browser JS). Every explorer was then challenged by an independent skeptic instructed to break its findings with its own searches: hunt for missed consumers of anything proposed for deletion, read both copies of anything proposed for merging, and check that the named tests really pin the behaviour.

**Totals: 220 findings — 140 upheld, 72 weakened (action corrected), 8 refuted — plus 52 findings the skeptics added.** A weakened finding is still true; its action, scope or risk changed, and the corrected action is the one to follow. A refuted finding must not be acted on in its original form.

The single most important constraint the audit surfaced: about half of the unit-test files assert regexes over the SOURCE TEXT of `src/**` and `templates/**`. Moving a line can turn a test red with identical behaviour, negative assertions go vacuous when a file is split, and a file read as text by a test is not dead even with zero importers.
